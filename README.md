# HTTP Speed Check

Консольная утилита измеряет скорость скачивания с указанного HTTP(S)-адреса. Она выполняет **10 последовательных GET-запросов** и полностью читает тело ответа перед следующим запросом.

## Запуск

Нужен Python 3.9 или новее. Устанавливать пакеты не нужно.

```bash
python3 speed_test.py "https://www.python.org/static/img/python-logo.png"
```

Для замера скорости подставьте прямую ссылку на файл размером несколько мегабайт. Картинка в примере подходит для быстрой проверки запуска.

Вывод реального запуска команды выше. В каждой строке указаны объём тела ответа и длительность запроса.

## Как считается результат

| Показатель | Расчёт |
| --- | --- |
| Среднее время запроса, мс | Сумма длительностей 10 запросов, делённая на 10 |
| Медиана времени, мс | Среднее двух центральных длительностей после сортировки |
| Скачано всего, байт | Сумма фактически прочитанных байтов тела ответа |
| Скорость, Мбит/с | Общий объём в байтах × 8 / суммарное время в секундах / 1 000 000 |

Таймер охватывает весь запрос, включая установку соединения, ожидание ответа и чтение тела. Поэтому результат характеризует загрузку с выбранного сервера и зависит от его задержки, размера файла и условий сети.

Тело читается блоками по 64 КиБ. При сетевой ошибке, неожиданном HTTP-статусе или обрыве передачи, который удалось обнаружить, утилита выводит номер запроса и причину, завершается с кодом 1. Тайм-аут блокирующей сетевой операции — 30 секунд.

## Проверка

```bash
python3 -B -m unittest -v
```

Один тест проверяет полный и обрезанный ответы на локальном HTTP-сервере. Второй сверяет расчёты отчёта на известных значениях. Для запуска тестов достаточно локальной сети на `127.0.0.1`.
